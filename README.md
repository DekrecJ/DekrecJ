## 01 // FEATURED BUILDS

### RepoDoctor AI — repository quality auditor

<a href="https://repodoctor-ai.repodoctor-ai.workers.dev">
  <img src="https://raw.githubusercontent.com/DekrecJ/repodoctor-ai/main/public/og.png" alt="RepoDoctor AI" width="100%" />
</a>

Audits public GitHub repositories against **30 objective rules** across documentation, security, testing, automation and maintenance. Produces a **0–100 score** plus actionable fixes without cloning or executing the target repository.

`TypeScript` · `React 19` · `Next.js / Vinext` · `Cloudflare Workers` · `Vitest`

### ShipKit — software delivery orchestration for coding agents

<a href="https://github.com/DekrecJ/Shipkit">
  <img src="https://raw.githubusercontent.com/DekrecJ/DekrecJ/main/assets/shipkit-flow.svg" alt="ShipKit lifecycle" width="100%" />

A structured delivery layer for AI coding agents such as Codex and Claude Code. ShipKit adds persistent project state, explicit lifecycle phases, validation gates, testing, security checks and release readiness instead of relying on an unstructured chat loop.

`Python` · `CLI` · `AI coding agents` · `Quality gates` · `GitHub Actions`
